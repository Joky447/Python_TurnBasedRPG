# Spells x Blades ⚔️

A 2D turn-based RPG built with Python and Pygame. Battle through 5 themed floors, build a roster of heroes, grow your skills and gear, and defeat each floor's boss to unlock the next.

## 🎮 Play the Game (No Installation Required)
You do not need to install Python to play the game. 
1. Download or clone this repository.
2. Open the `dist` folder.
3. Double-click the `.exe` file to launch the game immediately!

## 💻 For Developers (Running from Source)
### Requirements
- Python 3.x
- Pygame Community Edition

### Installation
1. Clone this repository:
   ```bash
   git clone [https://github.com/Joky447/Python_TurnBasedRPG.git](https://github.com/Joky447/Python_TurnBasedRPG.git)
Install the required Pygame library:

Bash
pip install pygame-ce
Launch the game:

Bash
python main.py
